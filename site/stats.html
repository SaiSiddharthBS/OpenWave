What these numbers mean

  • Downloads are not users. One person can download twice (a new phone, a reinstall), and a file shared over WhatsApp counts once, however many people install it.
  • Updates count too. When an app updates itself, it downloads the new version from GitHub, so later versions include people who updated.
  • Not counted: Docker pulls and people running the server from source. Installs through Obtainium are counted, since it downloads the same files.
  • Downloads, stars and forks are saved once a day by a GitHub workflow; the totals at the top are live.
