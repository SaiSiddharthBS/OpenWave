Install in a minute

Pick your device. Everything is free, and the source is on GitHub for anyone to check.

  1. Download OpenWave-Android.apk on your phone (Android 7 or later, 64-bit).
  2. Open it and allow your browser to "install unknown apps" when Android asks, then tap Install.
  3. Open OpenWave. Everything runs on your phone. For automatic updates, add this project to Obtainium.
  1. Download for Apple Silicon (M1–M4) or for Intel Macs. Not sure which? Apple menu → About This Mac → "Chip".
  2. Open the file and drag OpenWave into Applications.
  3. Open OpenWave. If macOS says it can't verify the app, open System Settings → Privacy & Security, scroll down and click Open Anyway. You only do this once.
  1. Download OpenWave-Windows-Setup.exe (Windows 10 or 11).
  2. Run it. If Windows shows "Windows protected your PC", click More info → Run anyway. No admin password is needed.
  3. Start OpenWave from the Start menu or the desktop shortcut.
  1. Download OpenWave-Linux-x86_64.AppImage.
  2. Make it runnable: right-click → Properties → "Allow executing as program", or run chmod +x OpenWave-*.AppImage.
  3. Double-click it. It opens in its own window (Chrome, Chromium, Edge or Brave needed for the app window).
  1. Run docker run -d -p 8787:8787 -v openwave:/data --restart unless-stopped ghcr.io/saisiddharthbs/openwave
  2. Open http://<server>:8787 on any device. Everyone in the house gets a profile.
  3. Optional: put it behind HTTPS (Tailscale, Cloudflare Tunnel or Caddy) to listen anywhere.

On your phone

Android: install the Android app. It runs everything on the phone. iPhone: play from the OpenWave on your computer, with the same profiles, playlists and likes:

  1. On your computer, open OpenWave → Settings → Phone and switch it on.
  2. Scan the QR code with your phone's camera.
  3. Add it to your home screen: on iPhone, Safari → Share → Add to Home Screen. On Android, Chrome → ⋮ → Install app.
